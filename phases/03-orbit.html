FASE 03 · ORBIT

Órbita: RAG con Azure AI Search

Órbita estable alcanzada. Conecta tus agentes autónomos a una base documental de misiones reales a Marte. Aprende a implementar RAG (Retrieval-Augmented Generation) de extremo a extremo: desde la descarga de documentos y almacenamiento en Azure Blob Storage, hasta la indexación híbrida con embeddings vectoriales, reordenamiento semántico y orquestación con Microsoft Agent Framework y Azure AI Foundry.

En esta fase trabajamos con press kits y reportes oficiales de la NASA sobre misiones históricas (Perseverance, Curiosity, InSight, MAVEN, MRO y Phoenix). El agente utilizará Azure AI Search como herramienta de recuperación para formular respuestas verificables, citando página y fuente documental sin alucinar.

Preparación Conceptos clave 1 · Descarga de datos 2 · Blob Storage 3 · Índice y Chunking 4 · Agente con RAG 5 · Comparación y Reranker 6 · Agente en Foundry Checkpoint

Preparación del Entorno

Para esta fase necesitas Python 3.10 o superior, Azure CLI instalado y acceso a los siguientes recursos en Azure:

  • Azure OpenAI / AI Foundry: despliegues de un modelo de chat (p.ej. gpt-4o-mini) y de embeddings (text-embedding-3-small).
  • Azure AI Search: servicio de búsqueda con soporte semántico (Semantic Ranker).
  • Azure Storage Account: contenedor de blobs (mars-rag) para almacenar los PDFs originales.
  • Azure AI Foundry Project: (opcional, para el paso 6) proyecto con conexión registrada hacia Azure AI Search.

Conceptos Clave de RAG

RAG

Retrieval-Augmented Generation: el agente extrae evidencia relevante desde documentos antes de generar la respuesta.

Chunking

División del texto en fragmentos (chunks) con solapamiento (overlap) para mantener el contexto semántico exacto.

Búsqueda Híbrida

Combina búsqueda léxica (BM25 por palabras clave) con búsqueda vectorial (embeddings semánticos densos).

Semantic Ranker

Modelo de Deep Learning (L2) que reordena los resultados según su relevancia semántica real con la pregunta.

Paso 2 · Publicación en Azure Blob Storage

tutorial/02_prepare_and_embed.py toma los PDFs descargados y los carga al contenedor de Azure Blob Storage (AZURE_STORAGE_CONTAINER). Al subir cada PDF, inyecta los metadatos de negocio (título, misión, categoría, URL de fuente) directamente en las propiedades del blob y genera el archivo data/blob_manifest.json.

Código del script tutorial/02_prepare_and_embed.py:

import json
import os
from pathlib import Path

from azure.core.exceptions import HttpResponseError, ResourceExistsError
from azure.identity import DefaultAzureCredential
from azure.storage.blob import BlobServiceClient, ContentSettings
from dotenv import load_dotenv

SCRIPT_DIR = Path(__file__).resolve().parent
PHASE_DIR = SCRIPT_DIR.parent
load_dotenv(PHASE_DIR / ".env")

DATA_DIR = PHASE_DIR / "data"
METADATA_FILE = DATA_DIR / "metadata.json"
OUTPUT_FILE = DATA_DIR / "blob_manifest.json"

AZURE_STORAGE_CONNECTION_STRING = os.getenv("AZURE_STORAGE_CONNECTION_STRING")
AZURE_STORAGE_ACCOUNT_NAME = os.getenv("AZURE_STORAGE_ACCOUNT_NAME")
AZURE_STORAGE_CONTAINER = os.environ["AZURE_STORAGE_CONTAINER"]
AZURE_STORAGE_BLOB_PREFIX = os.getenv("AZURE_STORAGE_BLOB_PREFIX", "mars-rag").strip("/")

def create_blob_service() -> BlobServiceClient:
    if AZURE_STORAGE_CONNECTION_STRING:
        return BlobServiceClient.from_connection_string(AZURE_STORAGE_CONNECTION_STRING)
    account_url = f"https://{AZURE_STORAGE_ACCOUNT_NAME}.blob.core.windows.net"
    return BlobServiceClient(account_url=account_url, credential=DefaultAzureCredential())

def blob_name_for(filename: str) -> str:
    return f"{AZURE_STORAGE_BLOB_PREFIX}/{filename}" if AZURE_STORAGE_BLOB_PREFIX else filename

def main():
    print("--- Preparando PDFs para Azure AI Search ---")
    if not METADATA_FILE.exists():
        print("No se encontró metadata.json. Ejecuta primero 01_download_data.py")
        return

    with METADATA_FILE.open("r", encoding="utf-8") as f:
        downloaded_files = json.load(f)

    blob_service = create_blob_service()
    container_client = blob_service.get_container_client(AZURE_STORAGE_CONTAINER)

    try:
        container_client.create_container()
        print(f"Contenedor creado: {AZURE_STORAGE_CONTAINER}")
    except ResourceExistsError:
        print(f"Usando contenedor existente: {AZURE_STORAGE_CONTAINER}")

    manifest = []
    for document in downloaded_files:
        filepath = DATA_DIR / document["filename"]
        if not filepath.exists():
            continue

        blob_name = blob_name_for(document["filename"])
        blob_client = container_client.get_blob_client(blob_name)
        print(f"Subiendo: {document['title']} -> {blob_name}")

        with filepath.open("rb") as pdf_file:
            blob_client.upload_blob(
                pdf_file,
                overwrite=True,
                metadata={
                    "title": document["title"],
                    "source_url": document["url"],
                    "category": document["category"],
                    "mission": document["mission"],
                },
                content_settings=ContentSettings(content_type="application/pdf"),
            )

        manifest.append({
            "title": document["title"],
            "filename": document["filename"],
            "blob_name": blob_name,
            "source_url": document["url"],
            "category": document["category"],
            "mission": document["mission"],
        })

    with OUTPUT_FILE.open("w", encoding="utf-8") as f:
        json.dump(manifest, f, ensure_ascii=False, indent=2)

    print(f"\nPDFs publicados en Blob Storage: {len(manifest)}")
    print(f"Manifest guardado en: {OUTPUT_FILE}")

if __name__ == "__main__":
    main()

Paso 3 · Índice Vectorial y Skillset con Azure AI Search

tutorial/03_setup_search_index.py automatiza la configuración de 4 artefactos en Azure AI Search:

  1. Índice Vectorial: declara campos de texto (content, title, source_url) y un vector de 1536 dimensiones (content_vector) con algoritmo HNSW y configuración de Semantic Ranker (rag-semantic-config).
  2. Origen de Datos (Data Source): conecta con el contenedor de Blob Storage.
  3. Skillset: incluye #Microsoft.Skills.Text.SplitSkill para dividir en páginas o fragmentos de 3500 caracteres con 500 de solapamiento, y #Microsoft.Skills.Text.AzureOpenAIEmbeddingSkill para generar los embeddings automáticamente con text-embedding-3-small.
  4. Indexer: orquesta la extracción periódica de PDFs, ejecución del skillset e indexación continua.

Paso 4 · Agente Autónomo con Herramienta RAG

En tutorial/04_agent_with_rag.py unimos Microsoft Agent Framework con el índice de búsqueda. El flujo consta de:

  • recuperar_conocimiento(query): vectoriza la pregunta con embedding_client, ejecuta búsqueda híbrida en search_client con Semantic Ranker y compone los pasajes recuperados.
  • Decorador @tool(approval_mode="never_require"): convierte la función en una herramienta accesible por el agente.
  • chat_client.as_agent(): define el agente con instrucciones explícitas para forzar la consulta a la herramienta antes de responder y exigir la cita de fuentes.

Código del script tutorial/04_agent_with_rag.py:

import os
from pathlib import Path
from typing import Annotated
from dotenv import load_dotenv
from pydantic import Field
from azure.identity import DefaultAzureCredential
from azure.search.documents.models import VectorizedQuery

from agent_framework import tool
from agent_framework.openai import OpenAIChatClient, OpenAIEmbeddingClient
from azure.search.documents.aio import SearchClient

SCRIPT_DIR = Path(__file__).resolve().parent
PHASE_DIR = SCRIPT_DIR.parent
load_dotenv(PHASE_DIR / ".env")

AZURE_OPENAI_ENDPOINT = os.environ["AZURE_OPENAI_ENDPOINT"].rstrip("/")
CHAT_MODEL = os.environ["AZURE_OPENAI_CHAT_MODEL"]
EMBEDDING_MODEL = os.environ["AZURE_OPENAI_EMBEDDING_MODEL"]
AZURE_SEARCH_ENDPOINT = os.environ["AZURE_SEARCH_ENDPOINT"].rstrip("/")
AZURE_SEARCH_INDEX = os.environ["AZURE_SEARCH_INDEX"]

credential = DefaultAzureCredential()

# 1. Clientes
chat_client = OpenAIChatClient(model=CHAT_MODEL, azure_endpoint=AZURE_OPENAI_ENDPOINT, credential=credential)
embedding_client = OpenAIEmbeddingClient(model=EMBEDDING_MODEL, azure_endpoint=AZURE_OPENAI_ENDPOINT, credential=credential)
search_client = SearchClient(endpoint=AZURE_SEARCH_ENDPOINT, index_name=AZURE_SEARCH_INDEX, credential=credential)

# 2. Recuperación híbrida con Semantic Ranker
async def recuperar_conocimiento(query: str, top_k: int = 5) -> str:
    """Traduce la pregunta a vector, busca en el índice y aplica Rerank semántico."""
    emb_resp = await embedding_client.get_embeddings(values=[query])
    vector = emb_resp[0].vector
    vector_query = VectorizedQuery(vector=vector, k_nearest_neighbors=10, fields="content_vector")
    
    results = await search_client.search(
        search_text=query,
        vector_queries=[vector_query],
        select=["title", "content", "source_url"],
        query_type="semantic",
        semantic_configuration_name="rag-semantic-config",
        top=top_k,
    )
    
    passages = []
    async for item in results:
        passages.append(
            f"Título: {item['title']}\n"
            f"Fuente: {item['source_url']}\n"
            f"Contenido: {item['content']}"
        )
        
    return "\n\n---\n\n".join(passages) if passages else "NO_SE_ENCONTRO_EVIDENCIA"

# 3. Herramienta (Tool) para el Agente
@tool(approval_mode="never_require")
async def buscar_en_base_documental(
    pregunta: Annotated[str, Field(description="Pregunta sobre misiones a Marte para buscar en la base documental.")]
) -> str:
    """Busca evidencia relevante en la base de datos de misiones a Marte."""
    print(f"\n[TOOL] El agente está buscando: '{pregunta}'...")
    return await recuperar_conocimiento(pregunta)

# 4. Agente con instrucciones estrictas de grounding
instrucciones_agente = """
Eres un asistente RAG especializado en documentos de misiones a Marte de la NASA.
Reglas:
1. Siempre llama a la herramienta de búsqueda antes de responder.
2. Responde SOLO con la información recuperada de los fragmentos.
3. Si no encuentras la respuesta, di "No encuentro evidencia suficiente".
4. Al final de tu respuesta, lista tus "Fuentes" citando el Título del documento.
"""

agente_rag = chat_client.as_agent(
    name="MarsRAG_Agent",
    instructions=instrucciones_agente,
    tools=[buscar_en_base_documental],
)

# 5. Ejecución
async def main():
    print("=== PROBANDO EL AGENTE RAG ===")
    pregunta = "¿Qué instrumento del rover Curiosity utiliza un láser para vaporizar rocas?"
    
    print(f"\nPregunta del Usuario: {pregunta}")
    print("Esperando que el Agente analice, consulte la herramienta y formule respuesta...\n")
    
    respuesta = await agente_rag.run(pregunta)
    
    print("\n=== RESPUESTA FINAL DEL AGENTE ===")
    print(respuesta.text)
    
    await search_client.close()

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())
