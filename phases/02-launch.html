Lanzamiento: Tools y MCP

Amplía tu agente con funciones Python y con un servidor MCP local. Primero usarás herramientas para responder preguntas de la misión; después conectarás una herramienta, un recurso y un prompt de clima marciano.

El plan de viaje, el inventario y el clima de estos ejercicios son datos simulados. La hora procede del reloj del sistema y el cálculo de viaje es una estimación simplificada.

Preparación 1 · Tools 2 · Servidor MCP 3 · Chat MCP Checkpoint

Preparación

Necesitas Python 3.10 o posterior, uv y una clave de OpenAI. Trabaja desde la raíz de mars-mission-labs.

Copia .env.example a .env en esa raíz y configura:

OPENAI_API_KEY=sk-tu-api-key-aqui

Cada archivo declara sus propias dependencias con metadatos PEP 723; uv run prepara el entorno al ejecutarlo. Los ejemplos usan gpt-4o-mini mediante OpenAIChatCompletionClient. No publiques tu archivo .env.

Conceptos clave

Tool calling

El agente elige una función cuando necesita datos o un cálculo para responder.

Datos simulados

Algunas funciones devuelven una muestra local, sin consultar Internet ni una base real.

MCP

Un servidor publica herramientas, recursos y prompts mediante un protocolo común.

stdio

El chat inicia el servidor local como proceso y se comunica con él por entrada y salida estándar.

Paso 1 · Herramientas Python

01_tools.py registra cinco funciones directamente en client.as_agent(..., tools=[...]). Sus nombres, parámetros y descripciones ayudan al agente a escogerlas; este ejemplo no usa un decorador @tool.

get_current_time lee el reloj local y get_current_time_in_timezone acepta una zona IANA, como America/Lima. web_search y query_database consultan muestras locales del plan y el inventario. travel_time_calc divide distancia entre velocidad y convierte las horas a días; supone velocidad constante y trayectoria directa. El script requiere agent-framework-openai, python-dotenv y tzdata.

Este es el archivo completo del laboratorio:

# /// script
# requires-python = ">=3.10"
# dependencies = [
#     "agent-framework-openai",
#     "python-dotenv",
#     "tzdata",
# ]
# ///
"""MISION MARTE - Fase 02: chat con herramientas locales y datos simulados."""

import asyncio
import os
import unicodedata
from datetime import datetime
from zoneinfo import ZoneInfo, ZoneInfoNotFoundError

from agent_framework.openai import OpenAIChatCompletionClient
from dotenv import load_dotenv

INSTRUCTIONS = (
    "Eres el Control de Mision de MISION MARTE. Coordinas la mision a Marte "
    "y das briefings tecnicos a la tripulacion. Usa terminologia espacial y se conciso. "
    "Para consultar la hora actual, usa una de las herramientas disponibles. "
    "Si el usuario indica una zona horaria, usa get_current_time_in_timezone con un nombre IANA, "
    "por ejemplo America/Lima. Si pregunta por una respuesta anterior, usa la conversación "
    "sin volver a consultar la hora. Usa web_search para consultar el plan de viaje simulado "
    "a Marte, query_database para el inventario simulado de la misión y travel_time_calc "
    "para estimar la duración del trayecto. Cuando respondas con resultados de web_search o "
    "query_database, empieza la respuesta con 'Datos simulados:' y no inventes resultados "
    "adicionales. El cálculo de viaje supone velocidad constante y trayectoria directa. "
    "Responde directamente, sin anteponer tu nombre ni etiquetas."
)
SIMULATED_OXYGEN_TANKS_AVAILABLE = 28


def normalize_text(value: str) -> str:
    """Quita diferencias de mayúsculas y acentos para comparar la muestra."""
    return "".join(
        character
        for character in unicodedata.normalize("NFKD", value.casefold())
        if not unicodedata.combining(character)
    )


def get_current_time() -> str:
    """Devuelve la hora actual en la zona horaria local del sistema."""
    return datetime.now().astimezone().strftime("%H:%M:%S %Z")


def get_current_time_in_timezone(timezone: str) -> str:
    """Devuelve la hora actual en una zona horaria IANA, como America/Lima."""
    try:
        current_time = datetime.now(ZoneInfo(timezone))
    except (ZoneInfoNotFoundError, ValueError, TypeError):
        return (
            f"Zona horaria inválida: {timezone}. Usa un nombre IANA, como America/Lima."
        )
    return f"{current_time:%H:%M:%S} ({timezone})"


def web_search(query: str) -> str:
    """Busca un plan de viaje a Marte en un índice local simulado."""
    normalized_query = normalize_text(query)
    if "marte" in normalized_query and any(
        term in normalized_query
        for term in ("plan", "ruta", "viaje", "trayecto", "itinerario")
    ):
        return (
            "El plan de viaje de MISIÓN MARTE contempla lanzamiento "
            "desde la Tierra, crucero interplanetario, inserción en órbita marciana "
            "y descenso a la superficie."
        )
    return "No hay resultados para esa consulta en la muestra simulada."


def query_database(table: str, item: str, status: str) -> str:
    """Consulta un inventario simulado de suministros de la misión."""
    normalized_table, normalized_item, normalized_status = (
        normalize_text(value.strip()) for value in (table, item, status)
    )
    if (
        normalized_table in {"inventario", "suministros"}
        and "oxigeno" in normalized_item
        and normalized_status in {"disponible", "disponibles", "available"}
    ):
        return (
            f"Hay {SIMULATED_OXYGEN_TANKS_AVAILABLE} tanques de oxígeno "
            "disponibles en el inventario de MISIÓN MARTE."
        )
    return "No hay datos para esos filtros en la muestra simulada."


def travel_time_calc(distance_km: float, speed_kmh: float) -> str:
    """Estima días de viaje con velocidad constante y trayectoria directa."""
    if distance_km <= 0 or speed_kmh <= 0:
        return "La distancia y la velocidad deben ser mayores que cero."
    travel_days = distance_km / speed_kmh / 24
    return (
        f"Estimación simplificada: {travel_days:.2f} días de viaje. "
        "Supone velocidad constante y trayectoria directa; no predice una misión real."
    )


async def main() -> None:
    """Inicia un chat que conserva la sesión y transmite las respuestas."""
    load_dotenv()
    api_key = os.getenv("OPENAI_API_KEY")
    if not api_key:
        raise SystemExit("Configura OPENAI_API_KEY en .env antes de iniciar el chat.")

    client = OpenAIChatCompletionClient(model="gpt-4o-mini", api_key=api_key)
    mission_control = client.as_agent(
        name="MissionControl",
        instructions=INSTRUCTIONS,
        tools=[
            get_current_time,
            get_current_time_in_timezone,
            web_search,
            query_database,
            travel_time_calc,
        ],
    )
    session = mission_control.create_session()

    print(
        "Control de Misión en línea. Plan de vuelo e inventario simulados. "
        "Escribe 'salir' para terminar.\n"
    )
    while True:
        try:
            user = input("Tú: ")
        except (EOFError, KeyboardInterrupt):
            print("\nCierre de comunicaciones. Cambio y fuera.")
            break
        if user.strip().lower() in {"salir", "exit", "quit"}:
            print("Cierre de comunicaciones. Cambio y fuera.")
            break

        print("CONTROL: ", end="", flush=True)
        async for chunk in mission_control.run(user, session=session, stream=True):
            if chunk.text:
                print(chunk.text, end="", flush=True)
        print("\n")


if __name__ == "__main__":
    asyncio.run(main())

Ejecuta desde la raíz de mars-mission-labs:

uv run phases/02-launch/01_tools.py

Prueba estas preguntas en el chat:

  • Busca el plan de viaje de MISIÓN MARTE.

La muestra del inventario contiene 28 tanques; la estimación del último ejemplo es 187,50 días. La respuesta del modelo puede variar, pero esos datos proceden de las funciones. Escribe salir para terminar.

Paso 2 · Servidor MCP de clima

02_mcp_server.py crea un servidor FastMCP local y publica get_mars_weather como herramienta, mars://weather-thresholds como recurso y mars_weather_briefing como prompt. Depende de mcp>=1.27,<2 y usa el transporte stdio.

El riesgo es alto si la visibilidad es Poor o la temperatura es ≤ −70 °C; si no, es medio cuando el viento supera 20 km/h. En los demás casos es bajo. La muestra fija de −63 °C, 24 km/h y visibilidad Good produce riesgo medio. No representa el clima actual de Marte.

Este es el archivo completo del servidor:

# /// script
# requires-python = ">=3.10"
# dependencies = [
#     "mcp>=1.27,<2",
# ]
# ///
"""MISION MARTE - Fase 02: servidor MCP de clima marciano simulado."""

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("MarsWeather", log_level="WARNING")
HIGH_RISK_TEMPERATURE_C = -70
MEDIUM_RISK_WIND_KMH = 20


def classify_mars_weather(
    temperature_c: int, wind_speed_kmh: int, visibility: str
) -> tuple[str, str]:
    """Clasifica el clima de forma determinista según los umbrales publicados."""
    if visibility == "Poor":
        return "Alto", "Visibilidad deficiente."
    if temperature_c <= HIGH_RISK_TEMPERATURE_C:
        return "Alto", (
            f"Temperatura de {temperature_c} °C, igual o menor a "
            f"{HIGH_RISK_TEMPERATURE_C} °C."
        )
    if wind_speed_kmh > MEDIUM_RISK_WIND_KMH:
        return "Medio", (
            f"Viento de {wind_speed_kmh} km/h, mayor a {MEDIUM_RISK_WIND_KMH} km/h."
        )
    return "Bajo", "Condiciones dentro de los umbrales de riesgo bajo."


@mcp.tool()
def get_mars_weather() -> dict[str, int | str | bool]:
    """Devuelve una muestra simulada del clima en Marte; no son datos actuales."""
    temperature_c = -63
    wind_speed_kmh = 24
    visibility = "Good"
    risk_level, risk_reason = classify_mars_weather(
        temperature_c, wind_speed_kmh, visibility
    )
    return {
        "temperature_c": temperature_c,
        "wind_speed_kmh": wind_speed_kmh,
        "visibility": visibility,
        "risk_level": risk_level,
        "risk_reason": risk_reason,
        "simulated": True,
    }


@mcp.resource("mars://weather-thresholds")
def mars_weather_thresholds() -> str:
    """Expone los criterios de riesgo para el briefing de clima marciano."""
    return (
        "Clasifica el riesgo de la muestra en este orden:\n"
        f"Alto: visibilidad Poor o temperatura menor o igual a {HIGH_RISK_TEMPERATURE_C} °C.\n"
        f"Medio: viento mayor a {MEDIUM_RISK_WIND_KMH} km/h.\n"
        "Bajo: cualquier otro caso."
    )


@mcp.prompt()
def mars_weather_briefing() -> str:
    """Prepara el formato del informe de clima para Control de Misión."""
    return (
        "Actúa como Control de Misión. Cuando pregunten por el clima en Marte, "
        "consulta get_mars_weather. La herramienta ya aplicó los umbrales del recurso: "
        "usa risk_level y risk_reason sin volver a calcularlos. "
        "Indica explícitamente que los datos son simulados. Responde en tres líneas: "
        "Estado actual, Nivel de riesgo y Recomendación operacional."
    )


if __name__ == "__main__":
    mcp.run(transport="stdio")

El siguiente paso inicia este servidor automáticamente; no necesitas abrirlo en otra terminal.

Paso 3 · Chat con MCP

03_mcp_chat.py inicia el servidor por stdio, lee su recurso y su prompt, y los incorpora a las instrucciones del agente. Luego MCPStdioTool le da acceso a la herramienta de clima. La sesión conserva el contexto entre preguntas. Este archivo declara agent-framework-openai, mcp>=1.27,<2, pydantic>=2,<3 y python-dotenv.

Este es el archivo completo del cliente:

# /// script
# requires-python = ">=3.10"
# dependencies = [
#     "agent-framework-openai",
#     "mcp>=1.27,<2",
#     "pydantic>=2,<3",
#     "python-dotenv",
# ]
# ///
"""MISION MARTE - Fase 02: chat con un servidor MCP local."""

import asyncio
import os
import sys
from pathlib import Path

from agent_framework import MCPStdioTool
from agent_framework.openai import OpenAIChatCompletionClient
from dotenv import load_dotenv
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from mcp.types import TextContent, TextResourceContents
from pydantic import AnyUrl

SERVER_PATH = Path(__file__).resolve().with_name("02_mcp_server.py")
INSTRUCTIONS = (
    "Eres el Control de Mision de MISION MARTE. Coordinas la mision a Marte "
    "y das briefings tecnicos a la tripulacion. Usa terminologia espacial y se conciso. "
    "Responde directamente, sin anteponer tu nombre ni etiquetas como 'MissionControl:'."
)


async def load_mcp_context() -> tuple[str, str]:
    """Lee el recurso y el prompt que el servidor MCP publica."""
    server = StdioServerParameters(command=sys.executable, args=[str(SERVER_PATH)])
    async with (
        stdio_client(server) as (read_stream, write_stream),
        ClientSession(read_stream, write_stream) as session,
    ):
        await session.initialize()
        resource = await session.read_resource(AnyUrl("mars://weather-thresholds"))
        prompt = await session.get_prompt("mars_weather_briefing")

    thresholds = "\n".join(
        item.text
        for item in resource.contents
        if isinstance(item, TextResourceContents)
    )
    briefing = "\n".join(
        message.content.text
        for message in prompt.messages
        if isinstance(message.content, TextContent)
    )
    if not thresholds or not briefing:
        raise RuntimeError(
            "El servidor MCP no devolvió el recurso o el prompt de clima."
        )
    return thresholds, briefing


async def main() -> None:
    """Inicia un chat con contexto MCP y acceso a la tool de clima."""
    load_dotenv()
    api_key = os.getenv("OPENAI_API_KEY")
    if not api_key:
        raise SystemExit("Configura OPENAI_API_KEY en .env antes de iniciar el chat.")

    thresholds, briefing = await load_mcp_context()
    client = OpenAIChatCompletionClient(model="gpt-4o-mini", api_key=api_key)
    instructions = f"{INSTRUCTIONS}\n\n{thresholds}\n\n{briefing}"

    async with MCPStdioTool(
        name="MarsWeather",
        command=sys.executable,
        args=[str(SERVER_PATH)],
        load_prompts=False,
    ) as weather_tool:
        mission_control = client.as_agent(
            name="MissionControl",
            instructions=instructions,
            tools=weather_tool,
        )
        session = mission_control.create_session()

        print(
            "Control de Misión en línea. Clima marciano simulado. Escribe 'salir' para terminar.\n"
        )
        while True:
            try:
                user = input("Tú: ")
            except (EOFError, KeyboardInterrupt):
                print("\nCierre de comunicaciones. Cambio y fuera.")
                break
            if user.strip().lower() in {"salir", "exit", "quit"}:
                print("Cierre de comunicaciones. Cambio y fuera.")
                break

            print("CONTROL: ", end="", flush=True)
            async for chunk in mission_control.run(user, session=session, stream=True):
                if chunk.text:
                    print(chunk.text, end="", flush=True)
            print("\n")


if __name__ == "__main__":
    asyncio.run(main())
