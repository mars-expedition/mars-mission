Encendido: Fundamentos del Framework

Los motores se encienden. En esta fase aprenderás los fundamentos de Microsoft Agent Framework, crearás tu primer agente y dominarás la diferencia entre ejecución síncrona (esperar la respuesta completa) y streaming (verla aparecer en tiempo real).

Conceptos Fundamentales

LLM

El cerebro base: el modelo de IA (como GPT) que entiende y genera texto.

Agent

Un asistente con rol e instrucciones propias que actúa por su cuenta.

Streaming

La respuesta aparece poco a poco, en tiempo real (como ver a alguien escribir).

Session

La memoria de la conversación: recuerda los mensajes anteriores.

Instalación

Usaremos uv, un gestor de paquetes de Python muy rápido. Trabajaremos con un script único: las dependencias viven dentro del propio archivo (formato PEP 723), así que no hay que crear proyecto ni entorno virtual — uv run lo prepara todo solo. 

# Crear el script (uv genera el bloque de metadatos)
uv init --script 01_hello_agent.py

# Declarar las dependencias dentro del propio script
uv add --script 01_hello_agent.py agent-framework-openai python-dotenv

¿Por qué agent-framework-openai y no agent-framework? El framework es modular: agent-framework-openai instala el conector de OpenAI y, junto con él, el núcleo (agent-framework-core) que necesitas. El meta-paquete completo agent-framework añade además todos los demás conectores (Azure, Foundry…) que aquí no usamos. Si en una fase futura necesitas otro proveedor, lo agregas con su propio uv add.

Tu Primer Agente

El ejemplo usa async/await: la forma de Python de pedir algo que tarda (como la respuesta del modelo) sin congelar el programa. Si es nuevo para ti, basta con seguir el patrón del ejemplo.

01_hello_agent.py

uv ya creó este archivo con el bloque # /// script /// de arriba (donde quedaron las dependencias). Reemplaza el cuerpo de ejemplo con este código y deja el bloque tal cual: 

# /// script
# requires-python = ">=3.10"
# dependencies = [
#     "agent-framework-openai",
#     "python-dotenv",
# ]
# ///
"""
MISIÓN MARTE - Fase 01: IGNITION
Tu primer agente con Microsoft Agent Framework.
"""
import asyncio
import os

from dotenv import load_dotenv
from agent_framework.openai import OpenAIChatCompletionClient

load_dotenv()


async def main() -> None:
    # Configurar cliente del modelo (OpenAI)
    client = OpenAIChatCompletionClient(
        model="gpt-4o-mini",
        api_key=os.getenv("OPENAI_API_KEY"),
    )

    # Crear agente con instrucciones de misión
    mission_control = client.as_agent(
        name="MissionControl",
        instructions="""Eres el Control de Misión de MISIÓN MARTE.
        
Tu rol es:
- Coordinar operaciones de la misión a Marte
- Dar briefings técnicos a la tripulación
- Responder consultas con precisión y claridad

Usa terminología espacial apropiada. Sé conciso pero informativo.""",
    )
    
    # ═══════════════════════════════════════════════════════════
    # MODO SÍNCRONO: Espera toda la respuesta
    # ═══════════════════════════════════════════════════════════
    print("MISIÓN MARTE - Control de Misión\n")
    print("=" * 50)
    
    response = await mission_control.run(
        "Control, solicito briefing del estado de la misión."
    )
    print(f"CONTROL: {response.text}")
    
    # ═══════════════════════════════════════════════════════════
    # MODO STREAMING: Respuesta token por token
    # ═══════════════════════════════════════════════════════════
    print("\n" + "=" * 50)
    print("Transmisión en tiempo real:\n")
    
    print("CONTROL: ", end="", flush=True)
    async for chunk in mission_control.run(
        "¿Cuál es el estado actual de los sistemas de propulsión?",
        stream=True,
    ):
        if chunk.text:
            print(chunk.text, end="", flush=True)
    
    print("\n")


if __name__ == "__main__":
    asyncio.run(main())

Configurar tu API key

Crea un archivo .env en la misma carpeta que el script, con tu API key de OpenAI:

# .env
OPENAI_API_KEY=sk-tu-api-key-aqui
¿Sin API key de pago? Usa GitHub Models gratis (clic para ver cómo)

GitHub Models te da acceso gratis a modelos como gpt-4.1-mini con solo tu cuenta de GitHub — sin tarjeta. (Límite del plan gratis: ~15 peticiones por minuto, de sobra para aprender.)

1) Genera un token gratis

  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Ponle un nombre y una expiración (p.ej. 30 días). En Repository access, «Public repositories» basta.
  3. En Permissions → Add permissions, busca Models y ponlo en Access: Read-only.
  4. Pulsa Generate token y copia el valor (empieza con github_pat_…); solo se muestra una vez.

Atajo: en github.com/marketplace/models abre un modelo → «Use this model» → «Create Personal Access Token» (proveedor GitHub, el gratis).

2) Pon el token en tu .env

# .env
GITHUB_TOKEN=github_pat_tu_token_aqui

3) Cambia el cliente en 01_hello_agent.py por esta versión:

client = OpenAIChatCompletionClient(
    model="openai/gpt-4.1-mini",
    api_key=os.getenv("GITHUB_TOKEN"),
    base_url="https://models.github.ai/inference",
)

Ejecutar

uv run 01_hello_agent.py

Síncrono vs Streaming

Modo síncrono: await agent.run(input) — El programa espera hasta recibir la respuesta completa. Útil cuando necesitas la respuesta entera antes de seguir (por ejemplo, para tomar una decisión o guardar el resultado).

Modo streaming: async for chunk in agent.run(input, stream=True) — Recibes la respuesta en fragmentos, en tiempo real. Ideal para interfaces tipo chat donde quieres mostrarla progresivamente.
