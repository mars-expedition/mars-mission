FUNDAMENTOS

Conceptos Clave

Lo esencial que necesitas saber antes de despegar.

LLM

El cerebro base. Un modelo de IA que comprende y genera lenguaje natural con razonamiento.

Agent

Sistema autónomo con rol definido, instrucciones específicas y capacidad de usar herramientas.

Tools

Funciones que el agente puede invocar para interactuar con sistemas externos y APIs.

Streaming

Respuestas en tiempo real, token por token. Mejor experiencia de usuario.
