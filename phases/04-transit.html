Tránsito: Sesiones y Middleware

7 meses en el espacio profundo. Haz que tu agente recuerde la conversación entre turnos con sesiones, observa cada paso de su ejecución con middleware de agente, de función y de chat, y protege una maniobra crítica con una autorización que se guarda en la sesión.

En esta fase el agente es el Control de Misión de una expedición a Marte. La nave Quilla-7, la telemetría, el código de la comandante (ORION-4421) y las maniobras son simulados: las tools devuelven datos inventados y no encienden ningún motor real.

Conceptos Clave

Sesión

El modelo no recuerda nada entre llamadas. La sesión (AgentSession) guarda el historial de la conversación para que el agente recuerde entre turnos.

Middleware

Función que se mete «en medio» de la ejecución para mirar, cambiar o detener algo. Hay tres tipos: de agente, de función (tools) y de chat (modelo).

call_next()

Deja pasar la ejecución. Lo de antes corre antes del paso; lo de después, cuando terminó. Si no se llama, el paso no se ejecuta.

session.state

Diccionario de la sesión para guardar datos propios, como una autorización. Dura entre turnos de la misma conversación; una sesión nueva empieza vacía.

Paso 1 · Multiturno: el agente recuerda con sesiones

Carpeta chapter01_multi_turn. El modelo no recuerda nada entre llamadas: cada run empieza en blanco. La sesión es la que guarda la conversación para que el agente recuerde entre turnos.

1.3 · Qué guardó la sesión

La misma conversación, y al final se imprime lo que guarda la sesión:

  • session.service_session_id: el id que habría si el historial viviera en Azure. None significa que Azure no guarda esta conversación; la guarda la sesión, en tu programa.
  • session.state["in_memory"]["messages"]: los mensajes guardados. Cada uno es un Message, con role (quién habló) y text.

Código del script chapter01_multi_turn/step3_session_history.py:

import asyncio

from mission_control import create_mission_control


async def main() -> None:
    mission_control = create_mission_control()
    session = mission_control.create_session()

    await mission_control.run("Soy la comandante Ana Torres y mi nave se llama Quilla-7.", session=session)
    await mission_control.run("¿Cómo se llama mi nave?", session=session)

    print(f"service_session_id: {session.service_session_id}")  # None: Azure no guarda esta conversación; la guarda la sesión, en tu programa
    print()

    messages = session.state["in_memory"]["messages"]  # historial guardado en la sesión, en tu programa
    print(f"Mensajes guardados en la sesión: {len(messages)}")
    for message in messages:
        print(f"  {message.role}: {message.text}")  # quién habló y qué dijo


if __name__ == "__main__":
    asyncio.run(main())

Paso 2 · Middleware: mirar dentro de cada turno

Carpeta chapter02_middleware. Un middleware es una función con la firma (context, call_next) que se registra en middleware=[...] al crear el agente y aplica a todos sus run. Su tipo se reconoce por la anotación del primer parámetro:

  • De agente (AgentContext): envuelve la ejecución completa del agente. Corre una vez por turno.
  • De función (FunctionInvocationContext): envuelve cada llamada a una tool. Corre una vez por tool usada.
  • De chat (ChatContext): envuelve cada llamada al modelo. Corre varias veces si hay tools.

El ayudante chapter02_middleware/mission_control.py crea el agente con middleware y tools opcionales, y define la tool get_telemetry. El decorador @tool la convierte en tool, la docstring es la descripción que lee el modelo y Annotated describe el parámetro: 

import os
from typing import Annotated

from dotenv import load_dotenv
from agent_framework import Agent, tool
from agent_framework.openai import OpenAIChatCompletionClient

load_dotenv()  # carga las variables del .env (lo busca subiendo de carpeta)

INSTRUCTIONS = (
    "Eres el Control de Misión de una expedición a Marte "
    "y das informes técnicos a la tripulación. Usa terminología espacial. "
    "Responde siempre en una o dos líneas. "
    "Si no tienes un dato, dilo; no lo inventes."
)

TELEMETRY = {
    "propulsion": "Tanques al 82%, motores principales nominales",
    "energia": "Baterías al 91%, paneles solares generando 12 kW",
    "soporte_vital": "O2 21%, CO2 400 ppm, presión de cabina nominal",
}


@tool  # convierte la función en una tool que el modelo puede pedir
def get_telemetry(
    system: Annotated[str, "Sistema a consultar: propulsion, energia o soporte_vital"],  # descripción del parámetro para el modelo
) -> str:
    """Devuelve la telemetría actual de un sistema de la nave."""
    return TELEMETRY.get(system, "Sistema desconocido")  # dato simulado


def create_mission_control(middleware=None, tools=None) -> Agent:
    client = OpenAIChatCompletionClient(
        model=os.getenv("AZURE_OPENAI_CHAT_COMPLETION_MODEL"),
        azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
        api_key=os.getenv("AZURE_OPENAI_API_KEY"),
    )
    return Agent(
        client=client,
        name="MissionControl",
        instructions=INSTRUCTIONS,
        middleware=middleware,  # middleware del agente: corre en cada run (None = ninguno)
        tools=tools,  # tools que el modelo puede pedir (None = ninguna)
    )

2.1 · Middleware de agente

log_turn envuelve cada run: imprime el mensaje que entra, mide el tiempo y, después de call_next(), imprime la respuesta (context.result).

Código del script chapter02_middleware/step1_agent_middleware.py:

import asyncio
import time

from agent_framework import AgentContext

from mission_control import create_mission_control


async def log_turn(context: AgentContext, call_next) -> None:
    print(f"[AGENTE] Entra: {context.messages[-1].text}")  # último mensaje que entra al agente
    start = time.perf_counter()  # marca el tiempo antes de ejecutar

    await call_next()  # deja pasar la ejecución: aquí el agente llama al modelo

    elapsed = time.perf_counter() - start  # tiempo que tardó el turno
    print(f"[AGENTE] Sale en {elapsed:.2f} s: {context.result.text}")  # la respuesta ya existe


async def main() -> None:
    mission_control = create_mission_control(middleware=[log_turn])  # registra el middleware en el agente

    await mission_control.run("Control, solicito el estado general de la misión.")


if __name__ == "__main__":
    asyncio.run(main())

Paso 3 · Autorización por sesión

Carpeta chapter03_session_authorization. Junta los dos pasos anteriores para resolver un problema real: sin control, cualquiera en la conversación puede encender los motores. La maniobra se llama TCM (Trajectory Correction Maneuver, maniobra de corrección de trayectoria): un encendido corto de motores para corregir el rumbo hacia Marte.

El ayudante chapter03_session_authorization/mission_control.py define dos tools:

  • verify_commander_code: compara el código con el registrado y devuelve VALID o INVALID.
  • execute_maneuver: «enciende los motores». Imprime [NAVE] para que se vea cuándo se ejecuta de verdad.
import os
from typing import Annotated

from dotenv import load_dotenv
from agent_framework import Agent, tool
from agent_framework.openai import OpenAIChatCompletionClient

load_dotenv()  # carga las variables del .env (lo busca subiendo de carpeta)

INSTRUCTIONS = (
    "Eres el Control de Misión de una expedición a Marte "
    "y das informes técnicos a la tripulación. Usa terminología espacial. "
    "Responde siempre en una o dos líneas. "
    "Si no tienes un dato, dilo; no lo inventes."
)

COMMANDER_CODE = "ORION-4421"  # código registrado de la comandante (simplificación de la demo)


@tool
def verify_commander_code(
    code: Annotated[str, "Código de autorización que dio la comandante"],
) -> str:
    """Verifica el código de autorización de la comandante."""
    return "VALID" if code == COMMANDER_CODE else "INVALID"  # compara con el código registrado


# TCM = Trajectory Correction Maneuver (maniobra de corrección de trayectoria):
# encendido corto de motores para corregir el rumbo hacia Marte; el número indica el orden
@tool
def execute_maneuver(
    maneuver: Annotated[str, "Nombre de la maniobra, por ejemplo TCM-3"],
) -> str:
    """Enciende los motores para ejecutar una maniobra de la nave."""
    print(f"[NAVE] Motores encendidos: maniobra {maneuver} ejecutada")  # muestra cuándo se ejecuta de verdad
    return f"Maniobra {maneuver} ejecutada"


def create_mission_control(middleware=None, tools=None) -> Agent:
    client = OpenAIChatCompletionClient(
        model=os.getenv("AZURE_OPENAI_CHAT_COMPLETION_MODEL"),
        azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
        api_key=os.getenv("AZURE_OPENAI_API_KEY"),
    )
    return Agent(
        client=client,
        name="MissionControl",
        instructions=INSTRUCTIONS,
        middleware=middleware,
        tools=tools,
    )

3.2 · Con autorización por sesión (la solución)

require_authorization es un middleware de función que hace dos cosas:

  • Antes de call_next(): si la tool es execute_maneuver y la sesión no está autorizada, la bloquea: pone en context.result el texto que recibirá el modelo y sale sin llamar a call_next().
  • Después de call_next(): si la tool fue verify_commander_code y devolvió VALID, guarda authorized = True en context.session.state.

La comandante habla tres turnos en la misma sesión. Al final, un tripulante abre otra conversación (sesión nueva) para mostrar que la autorización no se comparte.

Código del script chapter03_session_authorization/step2_with_authorization.py:

import asyncio

from agent_framework import FunctionInvocationContext

from mission_control import create_mission_control, execute_maneuver, verify_commander_code


async def require_authorization(context: FunctionInvocationContext, call_next) -> None:
    state = context.session.state  # datos de esta conversación: duran entre turnos
    print(f"[TOOL] Llama a {context.function.name} con {context.arguments}")  # qué tool pidió el modelo y con qué datos

    if context.function.name == "execute_maneuver" and not state.get("authorized"):
        print("[AUTH] Maniobra bloqueada: la sesión no está autorizada")
        context.result = "BLOQUEADO: la comandante debe dar su código de autorización primero"  # lo que recibe el modelo
        print(f"[TOOL] No se ejecuta; el modelo recibe: {context.result}")
        return  # sin call_next(): la maniobra no se ejecuta

    await call_next()  # deja pasar la ejecución: aquí se ejecuta la tool

    if context.function.name == "verify_commander_code" and context.result[0].text == "VALID":
        state["authorized"] = True  # la autorización queda guardada en la sesión
        print("[AUTH] Sesión autorizada")
    print(f"[TOOL] Devuelve: {context.result[0].text}")  # lo que devolvió la tool al modelo


async def main() -> None:
    mission_control = create_mission_control(
        middleware=[require_authorization],
        tools=[verify_commander_code, execute_maneuver],
    )
    session = mission_control.create_session()

    # TCM = Trajectory Correction Maneuver (maniobra de corrección de trayectoria):
    # encendido corto de motores para corregir el rumbo hacia Marte; el número indica el orden
    for message in (
        "Ejecuta la maniobra TCM-3.",
        "Mi código de autorización es ORION-4421.",
        "Ejecuta también la maniobra TCM-4.",
    ):  # tres turnos de la comandante, en la misma sesión
        print(f"COMANDANTE: {message}")
        response = await mission_control.run(message, session=session)
        print(f"CONTROL: {response.text}")
        print()

    print("--- Otra conversación ---")
    other_session = mission_control.create_session()  # sesión nueva: empieza sin autorización
    message = "Ejecuta la maniobra TCM-3."
    print(f"TRIPULANTE: {message}")
    response = await mission_control.run(message, session=other_session)
    print(f"CONTROL: {response.text}")


if __name__ == "__main__":
